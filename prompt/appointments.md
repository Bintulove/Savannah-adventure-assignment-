# Prompt B — Appointment Reminders (AIM + MAP)

## AIM Framework

**A — Audience:** Pregnant women in rural areas with limited transport  
**I — Instruction:** Create realistic appointment reminders  
**M — Mode:** SMS reminders optimized for timing and accessibility  

## MAP Framework

**M — Model Context:** Clinics operate on fixed schedules, transport is costly  
**A — Audience Context:** Users may live 3–10km from clinics, rely on CHWs  
**P — Purpose:** Improve antenatal attendance and reduce missed visits  

## Final Prompt

Generate SMS appointment reminders for pregnant women in rural Kenya and Uganda.

Include:
- Appointment date and time
- Suggested travel time based on distance
- Mention Community Health Worker (CHW) support
- Optional M-Pesa savings reminder for transport

Keep messages short, clear, and practical.
