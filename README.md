# AfyaTech Precision Prompting Challenge

## Overview
This project improves AI prompts for AfyaTech’s maternal health assistant designed for rural Kenya and Uganda. The goal is to make AI responses more accurate, culturally relevant, and practical for low-resource environments.

Early testing showed that generic prompts produced urban-biased advice that did not reflect real-world conditions such as local diets, transport challenges, community health worker (CHW) systems, and financial constraints.

## Objectives
- Improve maternal nutrition guidance using local foods
- Create realistic appointment reminder systems based on rural access challenges
- Design safe emergency triage prompts using structured reasoning
- Reduce hallucination and improve cultural alignment in AI outputs

## Frameworks Used
- AIM Framework (Audience, Instruction, Mode)
- MAP Framework (Model, Audience, Purpose)
- Chain-of-Thought reasoning
- Verifier Pattern for safety and clarification

## Contents
- Prompt A: Nutrition Advice (Localized dietary guidance)
- Prompt B: Appointment Reminders (Context-aware scheduling)
- Prompt C: Emergency Triage (Safe step-by-step reasoning)
- Reflection on AI’s role in maternal healthcare
- Scenario-based quiz responses

## Key Insight
Effective AI in healthcare must go beyond general knowledge and adapt to real-world constraints such as geography, culture, infrastructure, and affordability.
