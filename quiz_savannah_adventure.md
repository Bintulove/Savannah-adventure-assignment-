## 2. Verifier Pattern (Triage Safety)
Force clarification before advice:

- Ask symptom details first
- Do not respond immediately
- Only provide guidance after full input
- Escalate carefully if danger signs appear

## 3. Chain-of-Thought vs WHO Summary
Chain-of-thought improves value by adapting guidelines to real constraints like transport, cost, and clinic scarcity, making advice actionable rather than theoretical.

## 4. OCEAN Framework
- Observe: Identify data claims  
- Cross-check: Validate with WHO/2025 data  
- Evaluate: Detect inconsistencies  
- Audit: Trace source of error  
- Neutralize: Block incorrect data before publication
